# Code of Conduct

## Lekhak

**Version:** v0.6

**Status:** Active Development

**Last Updated:** July 2026

---

# Our Commitment

Lekhak is committed to fostering a welcoming, respectful, and collaborative environment for everyone.

Whether you are:

* reporting a bug
* proposing a feature
* improving documentation
* reviewing code
* participating in discussions
* contributing code

you are expected to help create a positive and professional community.

Everyone should feel comfortable contributing regardless of their experience level.

---

# Our Values

The community around Lekhak is built upon the following principles.

## Respect

Treat every contributor with respect.

Constructive disagreement is encouraged.

Personal attacks are not.

---

## Collaboration

Software improves through collaboration.

Help others learn.

Accept feedback gracefully.

Offer feedback thoughtfully.

---

## Curiosity

Questions are always welcome.

No contributor is expected to know everything.

Learning is an important part of open source.

---

## Quality

Prioritize thoughtful engineering over rushing features.

Every contribution should improve the project.

---

## Ownership

Contributors are encouraged to take responsibility for the quality of their work.

Before opening a Pull Request:

* Test your changes.
* Review your code.
* Update documentation when appropriate.
* Consider how the change affects future development.

---

# Expected Behaviour

Examples of behaviour that contribute to a positive community include:

* Being respectful during discussions.
* Giving constructive feedback.
* Helping new contributors.
* Explaining technical decisions clearly.
* Accepting different viewpoints professionally.
* Keeping discussions focused on improving the project.
* Respecting maintainers' decisions.

---

# Unacceptable Behaviour

The following behaviours are not acceptable:

* Personal attacks or harassment.
* Discrimination of any kind.
* Trolling or intentionally disruptive behaviour.
* Insults or abusive language.
* Publishing private information without permission.
* Spam or repeated off-topic discussions.
* Deliberately submitting malicious code.
* Knowingly introducing security vulnerabilities.
* Misrepresenting another contributor's work.

---

# Contribution Standards

When contributing to Lekhak, contributors should strive to:

* Follow the established project architecture.
* Reuse existing patterns whenever possible.
* Keep implementations simple and maintainable.
* Write readable code.
* Update documentation when behaviour changes.
* Respect existing coding conventions.
* Avoid unnecessary complexity.

Every contribution should leave the project in a better state than before.

---

# Communication Guidelines

Discussions should remain:

* Respectful
* Technical
* Honest
* Solution-oriented

Disagreements are normal in software development.

When disagreements occur:

* Focus on the problem rather than the person.
* Support opinions with reasoning.
* Be willing to reconsider your approach when presented with better alternatives.

The best ideas should win, regardless of who proposes them.

---

# Reporting Issues

If you discover:

* a bug
* incorrect documentation
* a usability issue
* a security concern

please report it through the appropriate GitHub channel.

Security vulnerabilities should follow the reporting process described in **SECURITY.md**.

---

# Maintainer Responsibilities

Project maintainers are responsible for:

* Reviewing contributions fairly.
* Explaining significant architectural decisions.
* Maintaining a respectful environment.
* Enforcing this Code of Conduct consistently.
* Prioritizing the long-term health of the project.

Maintainers may edit, reject, or request changes to contributions when necessary to preserve the project's quality and direction.

---

# Enforcement

Instances of unacceptable behaviour may result in actions including:

* Requesting changes in communication.
* Closing discussions that become unproductive.
* Rejecting contributions that violate project standards.
* Temporarily or permanently restricting participation in the project.

Enforcement decisions will be made with the goal of maintaining a healthy and constructive community.

---

# Attribution

This Code of Conduct is inspired by widely adopted open-source community standards, including the Contributor Covenant, and has been adapted to reflect the goals and culture of the Lekhak project.

---

# Final Note

Lekhak is more than a software project.

It is an effort to build thoughtful tools for writers and creators.

Every contribution—whether it is code, documentation, design, testing, or feedback—helps move the project forward.

Thank you for helping make Lekhak a welcoming, professional, and collaborative project.
